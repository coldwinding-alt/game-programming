# Moon Lantern Park Project Plan

## 1. Project Overview

- Project Name: Moon Lantern Park
- Genre: Halloween-themed 1v1 arcade basketball game
- Core Gameplay: Character versus, steal & shoot, skill activation, solo adventure progression
- Main Content: `8` characters, `8` adventure levels, quick match, two-player versus, training, tutorial, tournament

| Character | English Name | Skill | Skill Effect |
| --- | --- | --- | --- |

## 3. Level Design Overview

- Total Levels: `8`
- Level Structure: 1 guardian character + 1 themed mechanic + 1 exclusive ball skin / scene atmosphere per level
- Adventure Goal: Defeat each guardian stage by stage, collect all Lantern Sigils, and ultimately unlock the park exit

| Stage | Stage Name | Guardian | Stage Effect / Mechanic | Design Focus |
| --- | --- | --- | --- | --- |
| 1 | PUMPKIN GATEWAY | Scarecrow | Pure 1v1 basic duel, no special rules | An introductory stage to familiarize players with basic offense and defense. |
| 2 | CANDY ARCH STREET | Black Cat | Skill gauge charges faster | Encourages more frequent use of ultimate abilities. |
| 3 | LAUGHING MIRROR HOUSE | Ghost Clown | Double rim window — hits during the window score double | Emphasizes tempo control and burst scoring. |
| 4 | CANDLE HALL | Candleman | Both sides' skills auto-charge, but the player charges faster | Creates high-frequency skill battles. |
| 5 | FOG DOCK | Skull Pirate | Airborne basketballs are deflected by side wind | Emphasizes prediction, correction, and shooting touch. |
| 6 | BLOOD MOON TERRACE | Vampire | Overall match pace is increased | Raises pressure and reaction demands. |
| 7 | CLOCKTOWER GRAVEYARD | Reaper | All baskets in the last 15 seconds earn +1 extra point | Emphasizes late-game comebacks and clutch finishes. |
| 8 | MOON LANTERN DOME | Witch | Mechanic rotates every 10 seconds: Charge / Double / Wind / Speed | As the final boss stage, comprehensively tests the player's adaptability. |

## 4. Stage Mechanic Descriptions

| Mechanic | Effect |
| --- | --- |
| Basic Duel | No additional rules, pure fundamental versus. |
| Candy Charge | Skill energy accumulates faster. |
| Double Rim | Goals scored within the designated time window are doubled. |
| Candle Ring | Both sides' skills auto-charge; the player has a greater advantage. |
| Fog Wind | The ball is deflected by lateral air currents while in the air. |
| Blood Moon | Entire match speed is increased, tightening the pace. |
| Harvest Time | Every basket in the last 15 seconds earns +1 extra point. |
| Moon Mix | Multiple mechanics cycle in rotation, serving as the final comprehensive challenge. |
