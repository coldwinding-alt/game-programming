# AI and External Resource Declaration

Reviewed on: `2026-06-16`

This document is written to support the coursework requirement to declare external resources, templates, tutorials, assets, audio, images, fonts, and AI assistance.

It focuses on asset and resource provenance. Any separate AI assistance used for coding, report writing, debugging, or presentation preparation should also be declared in the final report or professionalism portfolio if applicable.

## Summary

Moon Lantern Park uses:

- ChatGPT image generation as the visual basis for project-specific game art.
- Local Python synthesis for 18 project-generated WAV sound effects.
- One CC0 background music track from OpenGameArt.
- Google Fonts under the SIL Open Font License.
- Unity/TextMesh Pro default package resources.
- A gameplay reference/inspiration from `Hot-Blooded Basketball`, with no copied code or copied assets.
