# mlpHudView API

`mlpHudView` is the view layer for the match HUD. All UI elements are created at runtime. `GameCore` holds an instance and drives it through the following interfaces.

---

## Data Updates

### `UpdateScore(int left, int right)`
Refreshes the scoreboard and the score shown on the pause screen.
```csharp
hud.UpdateScore(MatchData.MatchScore[0], MatchData.MatchScore[1]);
```

### `UpdateTimer(float secondsLeft)`
Refreshes the timer text and synchronizes the frozen time shown on the pause screen.
```csharp
hud.UpdateTimer(endTime - matchTime);
```

### `SetTimerVisible(bool visible)`
Shows or hides the match timer. Hidden in training / tutorial mode.

---

## Match Event Messages

### `ShowMessage(string message, float duration = 1.2f, bool showBackdrop = true)`
Shows a large message in the center of the screen (`"BASKET"`, `"3 POINT"`, `"GO!!!"`, etc.). The message text determines the text color.
```csharp
hud.ShowMessage("BASKET", 1.2f);
hud.ShowMessage("3 POINT", 1.2f, false);  // Do not show the backdrop
```

### `ShowBonusNotice(string message, float duration = 0.9f)`
Small bonus text in the upper-right corner (`"HELL DASH!"`, etc.). Includes a scale-in animation.

### `HideMessage()` / `HideBonusNotice()`
Hides the corresponding message.

---

## Pause

### `ConsumePauseCommand()`
Reads and clears the pause command generated by HUD buttons, returning an `mlpPauseCommand` enum value:
- `None` - No action
- `Toggle` - Toggle pause
- `Resume` - Resume the match
- `Menu` - Return to the main menu
```csharp
// Polled every frame by GameCore
HandlePauseCommand(hud.ConsumePauseCommand());
```

### `ShowPauseOverlay()` / `HidePauseOverlay()`
Shows / hides the pause overlay panel.

### `BeginResumeCountdown(float duration)` / `EndResumeCountdown()`
Hides the pause screen and starts the "RESUMING IN" countdown / restores the upper-right buttons after the countdown ends.

---

## Countdown

### `StartCountdown(float duration, string caption = "")`
Starts a countdown and shows an optional caption above the numbers.
```csharp
hud.StartCountdown(3f, "TIP OFF IN");    // Before the match
hud.StartCountdown(3f, "OVERTIME IN");   // Overtime
```

### `UpdateCountdown(float dt)`
Drives the countdown each frame. Returns `true` while it is still running, `false` when it ends.
```csharp
preMatchCountdown = hud.UpdateCountdown(dt);
if (!preMatchCountdown) { /* Countdown ended, whistle to start the game */ }
```

### `HideCountdown()`
Hides and resets the countdown state.

---

## Post-Match Results

### `ShowPostMatch(int winner, int leftScore, int rightScore)`
Shows the post-match result card. `winner < 0` means the left side wins, `> 0` means the right side wins. Player mode automatically shows `"VICTORY"` / `"DEFEAT"`, while spectator mode shows `"PLAYER 1 WINS"`.
```csharp
hud.ShowPostMatch(postMatchWinner, MatchData.MatchScore[0], MatchData.MatchScore[1]);
```

### `HidePostMatch()`
Hides the post-match card and restores the scoreboard.

---

## Per-Frame Drive

### `Update(float dt)`
Main HUD update loop: button hover detection, message fade-out, countdown pulse animation, and post-match card entrance animation.
```csharp
// Called every frame from GameCore.Update
hud.Update(dt);
```

---

## State Queries

| Property | Type | Description |
|------|------|------|
| `IsPostMatchVisible` | `bool` | Whether the post-match results UI is visible |
| `IsPauseOverlayVisible` | `bool` | Whether the pause overlay is visible |
