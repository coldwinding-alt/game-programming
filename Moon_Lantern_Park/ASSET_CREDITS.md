# Asset Credits and Provenance

Reviewed on: `2026-06-16`

This file is the top-level asset provenance index for the current Moon Lantern Park coursework build. It records what ships in the Unity project, where each asset category came from, how it was modified, and which detail document should be used as evidence during submission.

## Short Submission Statement

Moon Lantern Park uses project-authored visual assets, documented open-license fonts, one CC0 background music track, and project-generated sound effects.

- The project-specific game image assets are based on ChatGPT image generation and project-side processing, including selected AI outputs, cleaned cutouts, composites, atlases, masks, and locally generated UI derivatives for Unity runtime use.
- The 18 WAV sound effects were generated locally by a deterministic Python synthesis script and do not reuse external audio recordings or sound libraries.
- The background music file `bgm.ogg` uses `Hallow Quest_2` from Zane Little Music's OpenGameArt pack `Spooky Action Loop ["Hallow Quest"]`, licensed under `CC0`.
- The runtime font files are documented Google Fonts / SIL Open Font License files, with some legacy Unity filenames retained only for compatibility.
- Unity/TextMesh Pro default sample resources are kept separately from the project's AI-generated game art and are documented below.

## Working Rule For Later Cleanup

- Keep `ASSET_CREDITS.md` as the short index and update the detail documents when an asset category changes.
- If a new external asset is added, record the source URL, creator, license, access date, what was used unchanged, what was modified, and where it appears in the game.
- If a new AI-generated image is added, record the AI tool, prompt purpose or theme, generated output type, edits made, runtime path, and credit wording.
- Keep local tool scripts used as asset provenance evidence in version control when possible.
- Do not describe Unity/TextMesh Pro default package resources as project-authored AI image assets.
