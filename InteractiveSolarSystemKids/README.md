# Interactive Solar System for Kids

Unity 2022 short in-class assignment project based on `Interactive_Solar_System_Assignment_Short_Rubric.pdf`.

## What It Includes

- A complete Unity scene with `Sun`, `Earth`, and `Moon`.
- Clickable `Earth` and `Moon` objects.
- Smooth camera focus when a planet or moon is selected.
- A kid-friendly fact panel and a `Back` button to return to the main view.
- Rotation/orbit motion, materials, lighting, behaviors, camera interaction, and audio.

## How To Run

1. Open this folder in Unity Hub with Unity `2022.3.62f3c1`.
2. Open `Assets/Scenes/InteractiveSolarSystem.unity`.
3. Press Play.
4. Click `Earth` or `Moon`.
5. Press `Back`, right-click, or press `Esc` to return to the main view.

## Created Scripts

- `Assets/Scripts/SolarSystemExplorer.cs`
- `Assets/Scripts/SolarSystemTarget.cs`

The editor helper `Assets/Editor/CreateInteractiveSolarSystemScene.cs` can regenerate or validate the scene if needed.
