# Project Framing

Updated: `2026-05-08`

## Coursework Positioning

This is a Unity 2022 coursework project for a Halloween-themed `1v1` arcade basketball game.

The game takes gameplay inspiration from the H5 web game `热血篮球赛`: fast `1v1` match rhythm, readable movement and shooting, simple competitive feedback, and special-skill moments. The project should be described as gameplay-inspired by that H5 game, not as a line-by-line rewrite, source-code port, or complete remake of the original codebase.

The current Unity build focuses on:

- a playable match loop
- character-based selection
- `QUICK MATCH`, `2 PLAYERS`, `TRAINING`, and `TOURNAMENT` modes
- an 8-character Halloween roster
- a course-ready documentation and verification trail

## Agile Management Notes

The project is managed as a small agile coursework repository:

- `DOCS/SPRINT_PLAN.md` keeps the current kanban state, task granularity, acceptance criteria, and follow-up items.
- `TEST_LOG.md` records smoke tests, manual checks, known issues, and documentation audits.
- `ASSET_CREDITS.md` records active runtime assets and current replacement/provenance status.
- `DOCS/COURSEWORK_ASSET_REVIEW.md` separates safe submission wording from remaining provenance risks.

Future work should continue in small commits tied to a clear task, with each change updating the relevant task board, test log, or asset credit note when it affects the submitted project surface.
