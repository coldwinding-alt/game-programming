# Behavior Checklist

Use this list for manual parity checks before switching a migrated subsystem on by default.

## Menu and Flow

- [ ] Player Count menu opens on boot
- [ ] Match Type menu opens and returns correctly
- [ ] Quick Match setup updates character, difficulty, and ball selection correctly
- [ ] Training setup updates character and ball selection correctly
- [ ] Two Players setup updates both characters and ball selection correctly
- [ ] Tournament setup, bracket, and awards screens match the runtime baseline

## HUD and Pause

- [ ] Scoreboard portraits, names, scores, and timer match the baseline layout
- [ ] Countdown, popup messages, bonus notices, and post-match prompts match the baseline
- [ ] Pause overlay layout, portraits, score board, and buttons match the baseline
- [ ] Top-right pause, music, and help buttons retain hover and click behavior

## Gameplay

- [ ] Court, baskets, and ball appear at the same positions and sorting layers
- [ ] Tipoff, restart, and serve positions match the baseline
- [ ] Ball bounce, basket sensor scoring, and rim collisions behave the same
- [ ] Player movement, jump, pickup, steal, block, and super abilities behave the same
- [ ] Tournament advancement, return to menu, and repeated match loops behave the same
