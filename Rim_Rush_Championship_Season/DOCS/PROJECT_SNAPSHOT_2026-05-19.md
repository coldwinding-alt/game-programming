# Project Snapshot — 2026-05-19

## 这是什么游戏

Rim Rush: Championship Season 是一款 **2D 横版街机篮球 1v1 对战游戏**，Unity 2022 LTS 制作，万圣节主题。

- 玩法灵感来自 H5 游戏《热血篮球赛》：快节奏对抗、操作可读性强、反馈直接
- 侧视图（side-view），水平球场，两端各一个篮筐，玩家只在水平轴移动 + 垂直轴跳跃
- 固定分辨率 1066×640，正交相机 + 点过滤，像素画风格
- 全部游戏对象由 C# 代码过程式构建，无 prefab，单场景 `Main.unity`

## 玩家要做什么

玩家控制一名万圣节角色，在 60 秒内与对手进行 1v1 篮球对抗，目标是**比对手得更多分**。

核心操作：

| 操作 | 说明 |
|---|---|
| 移动 | 水平左右移动（持球时减速 15%） |
| 跳跃 | 垂直跳跃，用于争抢篮板、封盖、起跳投篮 |
| 投篮 | 松手释放篮球，带物理抛物线弧度 |
| 扣篮 | 近距离起跳后砸筐，成功率 90% |
| 空中接力 | 高弧度特殊投篮 |
| 冲刺 | 双击方向键快速突进，可被盖帽打断 |
| 抢断 | 靠近持球对手时尝试断球 |
| 盖帽 / 假动作 | 防守键，盖帽打断对方冲刺；松手即假动作诱骗对手起跳 |
| 超级技能 | 充能释放，四种类型：超级扣篮、超级冲刺、护盾、传送 |

得分规则：球穿过篮筐上方传感器再穿过下方传感器即计分，2 分（近距离）或 3 分（远距离）。60 秒打平进入 15 秒加时。

## 游戏模式

| 模式 | 说明 |
|---|---|
| QUICK MATCH | 单人 vs AI，4 档难度（Easy / Normal / Hard / Hell） |
| 2 PLAYERS | 本地双人对战，P1 WASD+B/V，P2 方向键+L/K |
| TRAINING | 无限时间练习，无对手计时压力 |
| TOURNAMENT | 8 人淘汰赛：2 组常规赛（组内循环）→ 半决赛 → 三四名决赛 → 总决赛，附颁奖台 |

## 角色阵容

8 个万圣节主题角色，各有一个独特超级技能：

PUMPKIN · FRANKENSTEIN · MUMMY · VAMPIRE · CANDLEMAN · SCARECROW · WITCH · BLACK CAT

角色动画由自研轻量 DragonBones 运行时（`DBLiteRuntime`）驱动，读取 JSON 骨架 + 纹理图集在运行时装配。

## 垂直切片（Vertical Slice）定义

一个可独立展示的、完整的、可玩的游戏片段，体现最终产品的核心体验。本项目的垂直切片为：

> **一次完整的 QUICK MATCH 对局：从菜单进入 → 选角 → 开球 → 60 秒对抗 → 得分 → 结算 → 返回菜单。**

这个切片覆盖了：

- 菜单导航与 UI 交互
- 角色选择流程
- 比赛核心循环（移动、跳跃、投篮、扣篮、抢断、盖帽、超级技能）
- AI 对手行为（4 档难度）
- 计时与计分系统
- HUD 实时信息展示
- 结算画面与返回流程

只要这个路径跑通、体验完整，游戏的核心价值就已经体现出来了。后续的 TOURNAMENT、双人对战、更多角色都是在这个切片基础上的扩展。
