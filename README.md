# Game Programming Coursework Projects

This repository is organized as a small Unity coursework monorepo. Each game lives in its own folder with its own `Assets`, `Packages`, and `ProjectSettings`, so the projects can be opened independently in Unity Hub.

## Projects

- `BasketballLegends2020/` - Halloween arcade basketball Unity project.
- `InteractiveSolarSystemKids/` - interactive solar system scene for the short in-class assignment.

## Unity Version

- Unity Editor: `2022.3.62f3c1`

## How To Open

1. Open Unity Hub.
2. Choose `Add project from disk`.
3. Select one project folder:
   - `BasketballLegends2020`
   - `InteractiveSolarSystemKids`
4. Open the scene listed in that project's README and press Play.

## Repository Notes

- Generated Unity folders such as `Library`, `Logs`, `Temp`, `Builds`, and `UserSettings` are intentionally ignored.
- Keep each project self-contained inside its own folder to avoid mixing Unity settings or scene references.
